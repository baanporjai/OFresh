O'Fresh Kiosk Simulator

จำลองหน้าจอ idle/attract ของเว็บ kiosk (index.html) วางไว้ในตำแหน่งจอสัมผัสจริงบนตัวตู้ ใช้พรีวิวก่อนอัปโหลดขึ้นตู้จริง — ไม่กระทบไฟล์ที่ deploy

ยังไม่มีสเปกจอจริงจากคู่มือเครื่อง ตัวเลขนี้กะจากรูปหน้าตู้ ปรับได้เพื่อเทียบกับจอจริงเมื่อยืนยันสเปกแล้ว

ตู้จริงอาจรัน WebView ที่ไว้ใจ JS ไม่ได้ — หน้านี้ถูกออกแบบให้ไม่ต้องพึ่ง JS อยู่แล้ว (auto-scroll เป็น CSS ล้วน, แต่ละภาษาแยกไฟล์) ติ๊กเพื่อพิสูจน์ว่าหน้ายังใช้ได้ปกติ

JS ปิดอยู่ — หน้ายังแสดงผลปกติ
